## ナレーション原稿（読み上げ用）

> 記号の意味：`／` = 軽く息を継ぐ　`＿＿` = 強く言う　`（間）` = 0.5秒止める

### S1｜0〜4秒
```
副業やりたいのに、／ 時間がない人。
```
- 語りかけるように。焦らせない
- 「時間がない」を少しゆっくり

### S2｜4〜8秒
```
これ知らないと、（間）＿一生このまま＿です。
```
- 「一生このまま」だけ強く、少し低い声で
- 言い切ったあと0.5秒空ける

### S3｜8〜12秒
```
原因、／ ChatGPTの使い方かもしれません。
```
- ここでトーンを上げる（解決に向かう合図）

### S4｜12〜17秒
```
私はこれで、／ 提案文が ＿1時間から15分＿ になりました。
```
- 数字を一番はっきり言う
- 「1時間」と「15分」の間に軽く間を置く

### S5｜17〜21秒
```
やったことは、（間）ひとつだけ。
```
- 「ひとつだけ」の前でしっかり止める
- ここが一番の引き（離脱を防ぐ）

### S6｜21〜26秒
```
最初に、／「あなたはプロのコピーライターです」って、／ 役割を渡すこと。
```
- カギカッコの中はゆっくり、区切って読む
- ここが動画の核。急がない

### S7｜26〜30秒
```
これだけで出力が変わります。／ 他のAI術はプロフィールに。
```
- 最後は軽く。売り込み感を出さない

## 録音のコツ（地声）

| 項目 | やり方 |
|------|--------|
| 場所 | 布団の近く・クローゼットの中。反響を減らすと一気にプロっぽくなる |
| 距離 | スマホを口から**15〜20cm**。近すぎると吹かれ音が入る |
| 録り方 | **1テイク通しで録る**。噛んだら最初から。切り貼りより自然になる |
| 声量 | 普段の会話より**少し小さめ**。TikTokは近距離で聞かれる |
| 速度 | 気持ちゆっくり。自分で「遅いかな」と思うくらいが丁度いい |
| アプリ | スマホの標準ボイスメモでOK。CapCutに直接読み込める |

**噛んでも撮り直しは3回まで。** 4回目以降は不自然になるので、多少の噛みは残したほうが人間味が出ます。

## CapCut 手順

1. `slides/out/day01/` の PNG 7枚をタイムラインに並べる
2. 各スライドの長さを上表の秒数に合わせる
3. 録音した音声をインポートして重ねる
4. 音に合わせてスライドの切り替え位置を微調整
5. BGM（Lo-fi）を `-18dB` で追加
6. S4の位置に画面録画を挿入（不透明度 30% で背景に敷く）
7. 書き出し：1080p / 30fps

**自動キャプションは不要。** スライド自体が全画面テキストなので、字幕を重ねると読みづらくなります。
