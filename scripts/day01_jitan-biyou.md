## 狙い

Day1でやることは商品紹介ではなく、**「この人は忙しい人向けの時短美容の人だ」と3秒で伝えること**です。
そのうえで、その場で試せる具体策を1つ渡します。

---

## ナレーション原稿

> `／` = 軽く息を継ぐ　`＿＿` = 強く言う　`（間）` = 0.5秒止める

### S1｜0〜4秒
```
美容に時間、／ かけられない人へ。
```
- 語りかけるように。責めない
- 「かけられない」を少しゆっくり

### S2｜4〜8秒
```
全部やろうとするから、（間）＿続かない＿んです。
```
- 「続かない」を強く、少し低く
- 言い切ってから0.5秒空ける

### S3｜8〜12秒
```
減らすべきなのは、／ ＿毎日やる工程＿のほう。
```
- ここで結論を先に出す（引きを作る）

### S4｜12〜17秒
```
毎日5分やるか、／ 週1で15分やるか。
```
- 2つの数字を対比させる。間を置いて読む

### S5｜17〜21秒
```
私が続いたのは、（間）後者でした。
```
- 「後者」の前でしっかり止める
- ここが一番の引き

### S6｜21〜26秒
```
頻度を下げて、／ 1回を厚くする。／ これだけです。
```
- 動画の核。急がない
- 「これだけです」は軽く落とす

### S7｜26〜30秒
```
他の時短のやり方は、／ プロフィールに。
```
- 売り込み感を出さない

**総文字数：** 約145字 → 自然な速度で28〜30秒

## スライド構成

| # | 背景 | 表示テキスト | 秒数 |
|---|------|------------|------|
| 1 | 黒 | 美容に時間<br>かけられない人へ | 0〜4 |
| 2 | 黒 | 全部やろうとするから<br>**続かない**（赤） | 4〜8 |
| 3 | 白 | 減らすのは<br>**毎日やる工程** | 8〜12 |
| 4 | 黒 | 毎日5分（赤）<br>週1で15分（緑） | 12〜17 |
| 5 | 黒 | 続いたのは<br>**後者** | 17〜21 |
| 6 | 白 | 「頻度を下げて<br>1回を厚くする」 | 21〜26 |
| 7 | 黒 | 他の時短法は<br>プロフィールに ↓ | 26〜30 |

**撮影素材：** 不要。全スライドがテキストのみで完結します。
（余裕があればS6の裏に手元カット——洗面台やデバイスを置く動作——を30%で敷くと質感が出ます）

## 録音のコツ

| 項目 | やり方 |
|------|--------|
| 場所 | 布団の近く・クローゼットの中。反響を減らす |
| 距離 | 口から**15〜20cm**。近すぎると吹かれ音が入る |
| 録り方 | **1テイク通し**。噛んだら最初から |
| 声量 | 普段の会話より少し小さめ |
| 速度 | 「遅いかな」と思うくらいが丁度いい |

**撮り直しは3回まで。** 4回目以降は不自然になります。
