# プロフィール設定（確定版）

TikTokアプリの「プロフィールを編集」にそのまま入力してください。

---

## アイコン

`assets/profile/icon_720.png`（720×720）

黒背景・白「時短」・緑の電源ボタン型リング。
60px表示での可読性を検証済み。

---

## ユーザー名（@）

```
jitan.beauty
```

**30日に1回しか変更できません。** 確定してから登録してください。

---

## ニックネーム（表示名）

```
時短美容｜美容家電レビュー
```

@は短く、表示名に検索キーワード（美容家電）を入れる分担にしています。

---

## 自己紹介

```
時間がない人の美容だけ話します
美容家電・頭皮ケアを実際に買って検証
毎晩21時更新
```

40文字。TikTokの上限80文字に収まっています。

**この3行の役割：**

| 行 | 役割 |
|---|------|
| 1行目 | 誰向けか（約束を1つだけ） |
| 2行目 | 何をする人か（「実際に買って」で信頼を作る） |
| 3行目 | いつ来ればいいか（再訪の理由） |

伸びていない参考アカウント（25フォロワー）は「美容雑学/垢抜け/スキンケアの雑学や…」と
キーワードを並べていました。伸びている方（11,200フォロワー）は一言で何をくれる人かを言っています。
**キーワードの羅列より、約束を1つ。**

「検証」という表現は薬機法上も安全です。効能を約束せず、買って試す事実だけを述べています。

---

## リンク欄

TikTokショップのアフィリエイト承認後に商品リンクを設置します。
それまでは空欄で構いません（無理にリンクを置くとフォロー率が下がります）。

---

## 設定の順番

1. アイコンを設定
2. ユーザー名を `jitan.beauty` に変更
3. 表示名・自己紹介を入力
4. TikTokショップのアフィリエイト申請を出す
5. Day1を 8/10（月）21:00 に投稿

---

## アイコンを作り直す場合

```bash
node slides/avatar.js            # 6案を720×720で出力
node slides/avatar.js --small    # 60px検証用も同時に出力
node slides/avatar.js --circle   # 円形クロップの確認
```

色や文字は `slides/avatar.js` の `variants` 配列で変更できます。
