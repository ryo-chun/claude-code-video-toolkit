# 動画書き出しツール

スライドPNGと音声から、投稿できるMP4を作ります。CapCutは不要です。

## 使い方

### 1. まず無音プレビューで尺を確かめる

```bash
node video/build.js day01
```

→ `video/out/day01_preview.mp4`（30秒・無音）

これを再生しながら読む練習をすると、本番の録音が一発で決まります。

### 2. 録音を乗せて完成させる

```bash
node video/build.js day01 --voice 録音.m4a --bgm lofi.mp3 --fit
```

→ `video/out/day01.mp4`（1080×1920 / 30fps / H.264）

## オプション

| オプション | 説明 |
|-----------|------|
| `--voice <file>` | 地声の録音。m4a / mp3 / wav すべて可 |
| `--bgm <file>` | BGM。自動で `-18dB` に下げ、終端3秒でフェードアウト |
| `--fit` | 録音の実尺に合わせて各スライドの表示秒数を比例調整する |

## `--fit` を付けるかどうか

| | 動作 | 使う場面 |
|---|------|---------|
| なし | spec の `sec` 通りの秒数で固定 | 録音を秒数に合わせて読んだ場合 |
| あり | 録音の長さに全体を伸縮 | 自然に読んで、後から映像を合わせる場合（**推奨**） |

`--fit` は全スライドを同じ倍率で伸縮します。特定の1枚だけズレる場合は
`slides/specs/dayXX.json` の `sec` を直してから、スライドを作り直してください。

## 表示秒数はどこで決まるか

`slides/specs/dayXX.json` の各スライドの `"sec": "0-4"` から計算します。
秒数を変えたいときはこの値を編集してください（スライドPNGの作り直しは不要）。

## 前提

`ffmpeg` と `ffprobe` にパスが通っていること。

```bash
ffmpeg -version
```
